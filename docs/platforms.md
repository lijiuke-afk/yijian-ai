# 微信、企业微信、QQ、WhatsApp 使用指南

一见AI通过视觉识别真实软件界面，结合当前消息、上下文和业务知识完成客户沟通任务。**个人微信也可以配置业务 AI Agent。**

| 平台 | 配置入口 | 常见用途 |
| --- | --- | --- |
| 个人微信 | 工作台 → 平台 → 微信 | 客户接待、业务答疑、资料发送和客户跟进 |
| 企业微信 | 工作台 → 平台 → 企业微信 | 售前售后、客户服务与资料触达 |
| QQ | 工作台 → 平台 → QQ | 业务咨询、社群互动和跟进 |
| WhatsApp | 工作台 → 平台 → WhatsApp | 跨境业务咨询与客户跟进 |

## 配置顺序

1. 登录目标平台的业务账号，确认聊天软件与一见AI均可正常使用。
2. 在「Agent」中准备身份、服务范围、知识库和资料。
3. 在对应平台选择当前Agent。
4. 配置昵称、群聊规则、名单与服务时间，保存设置。
5. 用自己的测试会话检查回复、资料发送和人工接手。

![四个平台的独立配置页入口](../assets/screenshots/platforms.png)

## 同一个业务使用多个平台

创建Agent时可以选择多个使用平台。创建完成后，在每个平台配置页分别选择这个Agent；平台账号、名单与工作时间按各自业务单独设置。

## 群聊与名单

群聊是否回复、何时判断消息，按应用显示的群聊开关、昵称和提及规则执行。名单应填写聊天列表中显示的准确会话名称。先在可控测试群中检查设置，再用于业务群。

## 平台与运行条件

持续运行需要电脑、网络、权限、客户端与相关服务可用。WhatsApp环境按当前版本引导配置。各平台的具体可用功能和适配条件，以所安装版本界面为准。

聊天整理页面当前展示的是「微信聊天整理」；上传记录包后按模板整理，不代表四个平台的全部聊天均自动实时同步。
