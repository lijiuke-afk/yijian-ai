# 纯视觉工作方式与账号使用说明

## 一见AI怎样操作聊天软件

一见AI通过视觉识别真实客户端的界面、会话和消息，结合上下文与业务知识判断如何回应，再通过系统辅助功能完成点击、输入等界面操作。

它采用屏幕交互方式，不以破解聊天软件底层协议的方式接入。屏幕录制权限用于识别界面，辅助功能权限用于完成界面操作。

## 账号安全与“不封号”问题

账号安全是一见AI技术路线的重点，纯视觉操作与破解底层协议的接入方式有区别。

接入方式与平台对账号行为的管理是两个层面。纯视觉本身不等于平台豁免，也不能单独证明任何账号、任何行为下都不会受到限制。使用时仍需遵守对应平台规则，按真实业务需要设置回复范围与跟进任务。

本仓库的截图和视频用于展示产品界面与使用流程，不代表平台对产品的认证，也不构成全场景零封号保证。需要了解实际运行方式和业务适配，可通过[首页微信二维码](../README.md#添加微信了解一见ai)联系演示。

## 数据与运行环境

本地运行指聊天界面的识别与操作在电脑端进行，不代表完全离线，也不代表所有数据只在电脑本地处理。知识库处理与模型调用等功能涉及网络服务。

在有权限处理的业务资料与会话范围内使用。向公开Issues提交截图或日志前，遮挡聊天隐私、联系方式、订单信息和密钥。
